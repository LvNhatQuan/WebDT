# DT E-Commerce Website

## Giới thiệu dự án
DT E-Commerce Website là một hệ thống website thương mại điện tử được xây dựng theo mô hình **ASP.NET Core MVC**, tách biệt rõ ràng giữa giao diện người dùng (Frontend), xử lý nghiệp vụ (Backend) và thiết kế trải nghiệm (UI/UX).

---

## Công nghệ sử dụng

| Backend | Frontend | UI / UX | Tool |
|--------|----------|---------|------|
| ASP.NET Core MVC | HTML5, CSS3 | Figma | Visual Studio |
| C# | Bootstrap | | Git |
| SQL Server | JavaScript | | GitHub |
| Authentication & Authorization | Razor View Engine | | SQL Server Management Studio |

---

## Chức năng chính
- Đăng ký / Đăng nhập người dùng
- Quản lý sản phẩm (CRUD)
- Danh mục sản phẩm
- Giỏ hàng
- Đặt hàng & thanh toán
- Quản lý đơn hàng
- Quản trị người dùng (Admin)
- Áp dụng mã giảm giá (Coupon)
- Phân quyền người dùng

### Yêu cầu hệ thống

- **.NET SDK 10**
- **SQL Server Management Studio (SSMS)**
- **Visual Studio 2026**

### Clone source code
Clone project từ GitHub về máy:
